# 📚 المكتبة الرقمية (Digital Library Platform)

> منصة إلكترونية متكاملة لإدارة وعرض خدمات المكتبة الرقمية، مصممة بتصميم عريضي جذاب، متجاوب بالكامل مع جميع الأجهزة (Responsive)، وداعمة للغة العربية (RTL).

---

## 🌟 المميزات الرئيسية

* **تصميم عصري وجذاب:** واجهة مستخدم تعتمد على لوحة ألوان احترافية (`#2e7eff`) مع خط **Cairo** المتناسق.
* **شريط إخبارك متحرك (News Ticker):** لعرض أحدث الأخبار والإعلانات الخاصة بالمكتبة بشكل سلس.
* **قائمة تنقل تفاعلية (Navbar):** مصممة بحركات انسيابية لمنع أي تداخل أو اهتزاز في الصفحة.
* **منصة تسجيل دخول وخروج متكاملة:** نموذج مصمم بعناية للمستخدمين مع حقول مخصصة وآمنة بصرياً.
* **نظام كروت تفاعلي (Cards Grid):** لعرض الأقسام أو الكتب بمرونة تامة تتناسب مع أحجام الشاشات المختلفة.
* **متجاوب بالكامل (Fully Responsive):** يعمل بكفاءة عالية على الهواتف الذكية، الأجهزة اللوحية، وشاشات العرض الكبيرة.

---

## 🛠️ التقنيات المستخدمة

* **HTML5** - هيكلة الصفحة الأساسية.
* **CSS3** - التصميم، التنسيقات، الألوان، والحركات الانسيابية (Animations & Flexbox/Grid).
* **Google Fonts (Cairo)** - لخطوط عربية واضحة ونقية.
